---
name: web-to-markdown
description: Use this skill when you need to gather information, read, or scrape content from a specific web page or URL.
---

When the user asks to gather information, read content, or scrape data from a specific website or URL, use the command-line interface provided in this repository to convert the web page into Markdown format.

1.  **Execute the CLI tool**: Run the following bash command in the repository root:
    `python3 cli.py "<URL>" -o <output_filename.md>`

    *Replace `<URL>` with the actual website address and `<output_filename.md>` with a descriptive filename.*

2.  **Read the output**: Once the command completes successfully, read the generated markdown file to access the content.

3.  **Use the content**: Use the information gathered from the markdown file to fulfill the user's request.
